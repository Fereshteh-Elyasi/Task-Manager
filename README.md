# Taskline — سیستم مدیریت تسک

اپلیکیشن مدیریت پروژه و تسک (شبیه کانبان) با فرانت‌اند **React** و بک‌اند **Laravel**.

- بورد کانبان با درگ‌ اند‌ دراپ
- پروژه‌ها، ستون‌ها، تسک‌ها، برچسب‌ها
- چک‌لیست، کامنت، پیوست فایل
- تقویم جلالی و صندوق ورودی
- احراز هویت با توکن (Laravel Sanctum)
- دعوت کاربر با ایمیل (ادمین)
