# فرانت Taskline — اصلاح‌شده برای لاراول

## نصب

محتوای `src/` و `vite.config.js` و در صورت نیاز `.env` را روی پروژه فرانت خودت کپی کن.

```env
VITE_API_URL=/api
```

پروکسی Vite به `http://127.0.0.1:8000` تنظیم شده.

```bash
npm run dev
```

لاراول باید روشن باشد: `php artisan serve`

## اصلاحات این بسته

1. `api.updateProject` → PATCH /projects/{id} (رفع خطای 405 تغییر نام پروژه)
2. ویرایش نام پروژه از Topbar (آیکون ✎)
3. ویرایش نام ستون (دوبار کلیک یا ✎)
4. پروکسی Vite به لاراول به‌جای PHP خام
5. پیام خطای واضح‌تر برای 405
6. همگام‌سازی عنوان بورد با نام پروژه

## بک‌اند

حتماً route و متد update پروژه را در لاراول داشته باش:

```
PATCH /api/projects/{id}
```

(در بسته taskflow-laravel-complete هم اضافه شده.)
